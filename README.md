# Flask & MongoDB Atlas Assignment

## Project Overview

This project is a Flask web application integrated with MongoDB Atlas.

The application provides:

- A JSON API route at `/api`
- A frontend form
- MongoDB Atlas data storage
- Success page after successful submission
- Error handling on the same form page

---

## Technologies Used

- Python
- Flask
- MongoDB Atlas
- PyMongo
- HTML
- CSS
- python-dotenv
